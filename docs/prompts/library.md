# Prompt Library for Skill Activation

This library contains ready-to-use prompts designed to trigger Antigravity skill auto-activation across various project types.

---

## Technical Development

### REST API Development
```
I'm building a REST API with [feature 1], [feature 2], and [feature 3]. This is a complex multi-step project that will require careful planning across multiple phases including design, development, testing, and deployment.
```

### Full-Stack Application
```
I need to build a full-stack [application type] with [frontend framework], [backend framework], and [database]. This is a multi-phase project requiring careful planning for both frontend and backend development.
```

### Mobile App Development
```
Create a mobile application for [purpose] with [key features]. This is a complex project requiring planning across design, development, testing, and deployment phases for both iOS and Android platforms.
```

## Research & Learning

### Technology Research
```
I need to research [technology/concept] for [purpose]. This is a multi-phase research task where I'll need to evaluate different approaches, document findings, and provide recommendations.
```

### Learning New Technology
```
Help me learn [technology/framework] through a structured multi-step learning plan. I need to understand core concepts, work through examples, build practice projects, and track my progress throughout the learning journey.
```

I need to refactor [codebase/module] to [improvement goal]. This is a complex multi-step project requiring careful planning to avoid breaking changes while improving [quality aspect].

## 💡 Trigger Optimization Tips

To increase the likelihood of skill activation (specifically for `planning-with-files`):
- **Complexity Keywords**: Use "complex", "multi-step", "multi-phase", "systematic".
- **Planning Keywords**: Use "careful planning", "structured approach", "organized tracking".
- **Deliverables**: Mention "documentation", "findings", "milestones", "roadmap".
